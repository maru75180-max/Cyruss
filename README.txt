TAPBIZ
======

1. Open PowerShell in this folder.
2. Run:
   py -m pip install -r requirements.txt
3. Then run:
   py app.py
4. Open Chrome:
   http://127.0.0.1:5000

The database.db file is created automatically.

IMPORTANT FOR NFC:
127.0.0.1 only works on the computer running the server. For an NFC tag that other phones can tap, the website must eventually have a public URL/domain.
